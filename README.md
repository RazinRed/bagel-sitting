# Bagel's Sitter Guide

A one-page care guide for Bagel's cat sitters: door safety, a tickable visit checklist, meal prep, litter, playtime and what to do if something's wrong.

## Files
- `index.html`: the whole site (HTML, CSS and JS in one file)
- `images/`: photos used on the page

## Hosting on GitHub Pages
1. Push this folder to a GitHub repo.
2. Go to **Settings > Pages**, set the source to **Deploy from a branch**, pick `main` and `/ (root)`.
3. The site appears at `https://<your-username>.github.io/<repo-name>/`.

Note: the repo and site will be public unless you use a private Pages setup, so the photos of your home will be visible to anyone with the link.
